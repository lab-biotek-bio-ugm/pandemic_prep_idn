Module 11: Multiplex Compatibility

Module 11 (scripts/m11_multiplex_checker.py, scripts/m11_triplex_checker.py, and rules/m11_multiplex.smk) is the final verification stage of the pipeline. It evaluates the physical and thermodynamic feasibility of mixing candidate diagnostic assays for multiple distinct pathogens into a single multiplex reaction vessel (Duplex, Triplex, Quadruplex, or generic N-Plex RT-RAA/qPCR panels).

🔬 Core Screening Capabilities

  1. Dynamic N-Plex Cross-Dimer Thermodynamics (\(\Delta G\)): Evaluates all inter-assay combinations across any number of targets (e.g. 6 oligos for Duplex, 9 oligos for Triplex, 12 oligos for Quadruplex: primers + probes). Uses IUPAC base expansion to test worst-case secondary structure binding energies across all degenerate variants.
  2. Dual Temperature Regimes:
    • \(39.0^\circ\text{C}\) (RT-RAA Isothermal): Reaction temperature for isothermal recombinase-mediated amplification.
    • \(55.0^\circ\text{C}\) (qPCR Benchmark): Thermal cycling annealing benchmark.
  3. Kinetic Melting Temperature Alignment (\(\Delta T_m\)): Verifies that the \(T_m\) delta across all primers in the reaction is \(\le 4.0^\circ\text{C}\) to maintain balanced amplification rates.
  4. Flexible Multi-Channel Fluorophore Palette: Verifies probe channel independence across target channels dynamically:
    • Target 1: 5'-FAM / 3'-BHQ1 (emission ~520 nm)
    • Target 2: 5'-HEX / 3'-BHQ1 (emission ~556 nm)
    • Target 3: 5'-Cy5 / 3'-BHQ2 (emission ~670 nm)
    • Target 4+: 5'-Cy3 / ROX / Texas Red / Atto 647N (dynamic palette extension)

🛠️ Multi-Target Batch Orchestrator

To run batching across multiple target virus configs and trigger Module 11 automatically, use the master batch script:

python scripts/run_multiplex_batch.py \
  --configs config/config_influenza_a_mp.yaml config/config_influenza_b_mp.yaml \
  --cores 64 \
  --snakemake-args "--use-conda --rerun-incomplete"

Passing Snakemake Flags

You can pass any standard Snakemake flag (such as --unlock, --use-conda, --rerun-incomplete, or --rerun-triggers mtime) directly through --snakemake-args:

# Example: Unlocking directory if previous run was interrupted
python scripts/run_multiplex_batch.py \
  --configs config/config_influenza_a_mp.yaml config/config_influenza_b_mp.yaml \
  --cores 64 \
  --snakemake-args "--unlock"

📊 Module Outputs

Module 11 generates three primary assets in results/multiplex-<build_a>_x_<build_b>/:

  1. multiplex_candidates.json: Structured dataset containing scores, full oligo sequence synthesis specs, \(T_m\), GC%, positions, and 9-pair cross-dimer \(\Delta G\) breakdown.
  2. multiplex_report.md: Human-readable synthesis table and top recommended pairs.
  3. multiplex_matrix.html: Interactive HTML compatibility matrix.
